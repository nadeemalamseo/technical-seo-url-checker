# Security

## Scope

This project makes outbound HTTP requests to URLs supplied by the operator. Treat URLs as untrusted input.

## Safe use

- Only check URLs you are authorized to access.
- Do not use the tool to bypass authentication or access controls.
- Respect site terms, rate limits, and network policies.
- Do not expose credentials, cookies, API keys, or private URLs in bug reports.
- Review redirects before using the tool against large or automated URL sets.

## Reporting a security concern

Do not publish sensitive details in a public issue. Contact the repository maintainer privately through the contact method available on the maintainer's GitHub profile.

This project does not promise that every network or application-layer risk is detected by the checker.
